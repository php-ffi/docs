`FFI\Parser\Parser` is the entry point. It takes all its options in the
constructor, so one instance can parse any number of headers.

## Parsing

`Parser::parse()` returns a list of the declarations written at the root of
the file, in order. A declaration with several declarators gives one node for
each of them.

```php
use FFI\Parser\Parser;

$declarations = new Parser()->parse('int a, *b, c[2];');

foreach ($declarations as $declaration) {
    echo $declaration->name->value . ': '
        . $declaration->type::class . "\n";
}

// a: FFI\Parser\Node\Type\BuiltinType\IntType
// b: FFI\Parser\Node\Type\PointerType
// c: FFI\Parser\Node\Type\ArrayType\SizedArrayType
```

What the nodes are is described in [Working with the AST](../ast/).

## Sources

`parse()` and `validate()` accept:

| Value | Meaning |
|---|---|
| `string` | The code of the header, never a path. |
| `SplFileInfo` | A file. |
| `resource` | A stream. |
| `Phplrt\Contracts\Source\ReadableInterface` | A phplrt source. |

```php
use FFI\Parser\Parser;

$declarations = new Parser()->parse(new SplFileInfo('header.h'));
```

Comments and lines that start with `#` (line markers, `#pragma`) are
skipped: the parser does not interpret directives.

## After the preprocessor

The parser needs **preprocessed** source. `Preprocessor::process()` returns a
`Result` object that the parser does not accept directly: cast it to a
string. See also [the preprocessor](/preprocessor/with-parser/).

```php
use FFI\Parser\Parser;
use FFI\Preprocessor\Preprocessor;

$result = new Preprocessor()->process(<<<'C'
    #define SIZE 4
    int buffer[SIZE];
    C);

$declarations = new Parser()->parse((string) $result);

echo $declarations[0]->type->size->raw . "\n";

// 4
```

## Checking the syntax

`Parser::validate()` returns `true` or `false` and builds no tree, so it is
faster than `parse()`. It accepts every extension the grammar knows,
whatever the preset.

```php
use FFI\Parser\Parser;

$parser = new Parser();

var_dump($parser->validate('int x;'));
var_dump($parser->validate('int x'));

// bool(true)
// bool(false)
```

## Constructor options

All arguments are optional, pass them by name.

| Argument | Default |
|---|---|
| `preset` | `Preset::default()`, see [Presets](../presets/). |
| `transformerRules` | The default transformers, see [Customizing](../customizing/). |
| `validatorRules` | The default validators, see [Customizing](../customizing/). |
| `sources` | A phplrt `SourceFactoryInterface` for strings, files, streams. |

`parse()` builds the tree, runs the transformers over it, then the
validators.
