A header rarely starts from nothing: GCC accepts `__attribute__`, MSVC
knows `__int64`, PHP FFI knows `uint8_t` without any `#include`. A
**preset** (`FFI\Parser\Preset`) is that knowledge as data:

| Property | Meaning |
|---|---|
| `features` | The extensions of C23 the parser accepts (`Feature` cases). |
| `typedefNames` | Identifiers read as types without a declaration. |

Pass it as the `preset` argument of `Parser`.

## Why it matters

Without the typedef names the tree is ambiguous. In `sizeof(uint8_t[4])`
the name `uint8_t` is a type if the compiler knows it, and a variable
otherwise:

```php
use FFI\Parser\Parser;
use FFI\Parser\Preset;

$source = 'int a = sizeof(uint8_t[4]);';

foreach ([Preset::default(), Preset::c23()] as $preset) {
    $parser = new Parser(preset: $preset);
    $init = $parser->parse($source)[0]->initializer;

    echo new ReflectionClass($init)->getShortName() . "\n";
}

// SizeOfTypeExpression
// SizeOfExpression
```

## Choosing a preset

| Factory | Contents |
|---|---|
| `Preset::default()` | Every extension and the names of every compiler. The default of `Parser`. |
| `Preset::c23()` | Plain C23: no extensions, no typedef names. |
| `Preset::gcc()` | GCC extensions and built-in types. |
| `Preset::clang()` | Clang and GCC extensions. Arguments: `ClangTarget $target`, `bool $isMsExtensionsEnabled` (`-fms-extensions`). |
| `Preset::msvc()` | MSVC extensions and types (`__int64`...). |
| `Preset::php()` | What `FFI::cdef()` accepts, with `uint8_t`, `size_t`... |

To check a header for `FFI::cdef()` use `Preset::php()`: it rejects what PHP
FFI rejects, such as block pointers or `__forceinline`.

An extension the preset does not accept is a `SyntaxErrorException`:

```php
use FFI\Parser\Exception\SyntaxErrorException;
use FFI\Parser\Parser;
use FFI\Parser\Preset;

$parser = new Parser(preset: Preset::c23());

try {
    $parser->parse('int * __attribute__((unused)) p;');
} catch (SyntaxErrorException $e) {
    echo $e->getMessage() . "\n";
}

// Syntax error, the extension "GnuAttributes" is not enabled
```

## Your own preset

```php
use FFI\Parser\Parser;
use FFI\Parser\Preset;
use FFI\Parser\Preset\Feature;

$preset = new Preset(
    features: [Feature::ComplexIntegers],
    typedefNames: ['uint8_t', 'size_t'],
);

$parser = new Parser(preset: $preset);
$declaration = $parser->parse('size_t length;')[0];

echo $declaration->type->name->value . "\n";

// size_t
```

Some of the `Feature` cases:

| Case | Accepts |
|---|---|
| `GnuAttributes` | `__attribute__((aligned(8)))` |
| `AsmLabels` | `int f(void) __asm__("_f");` |
| `DeclSpec` | `__declspec(dllimport)` |
| `CallingConventions` | `__cdecl`, `__stdcall` |
| `BlockPointers` | `void (^callback)(int);` |
| `Nullability` | `int * _Nonnull p;` |
| `EscapeE` | `"\e"` |

The rest are in the `Feature` enum.
