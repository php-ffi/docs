Everything the package throws extends `FFI\Parser\Exception\ParserException`.
The kind of failure is the class:

| Class | Thrown when |
|---|---|
| `SyntaxErrorException` | The header is not valid, or uses an extension the [preset](../presets/) does not accept. |
| `ValidationException` | A validator rejects the tree, e.g. `long float x;`. |
| `InternalException` | The source cannot be read (a missing file, a value of an unsupported type) or cannot be analyzed for a reason other than its code. |
| `TraverserException` | A transformer or visitor broke the tree. |

```php
use FFI\Parser\Exception\ParserException;
use FFI\Parser\Parser;

function isValid(string $header): bool
{
    try {
        new Parser()->parse($header);

        return true;
    } catch (ParserException) {
        return false;
    }
}

var_dump(isValid('int x;'));
var_dump(isValid('int x'));

// bool(true)
// bool(false)
```

## Where is the error

`SyntaxErrorException` and `ValidationException` extend
`ParseRuntimeException`, with the read-only properties `source`, `offset`
(in bytes) and `length` (`null` if unknown). Printing the exception shows
the snippet of the source with a marker:

```php
use FFI\Parser\Exception\ParseRuntimeException;
use FFI\Parser\Parser;

try {
    new Parser()->parse("int x;\nint y y;");
} catch (ParseRuntimeException $e) {
    echo 'offset ' . $e->offset . "\n";

    $lines = explode("\n", (string) $e);

    echo implode("\n", array_slice($lines, 1, 3)) . "\n";
}

// offset 13
// 1 | int x;
// 2 | int y y;
//   |       ^
```

The printed form is the message line, the snippet, then the stack trace. The
example shows the snippet only.

## Validation errors

All violations are collected, and one `ValidationException` is thrown. Its
message is the first violation, with `(and N more)` if there are others, and
`violations` holds all of them (`message`, `offset`, `length`):

```php
use FFI\Parser\Exception\ValidationException;
use FFI\Parser\Parser;

try {
    new Parser()->parse("long float a;\nint b[3](void);");
} catch (ValidationException $e) {
    foreach ($e->violations as $violation) {
        echo $violation->offset . ': ' . $violation->message . "\n";
    }
}

// 0: Type specifiers `long float` should not be combined
// 19: Element type of an array should not be a function
```
