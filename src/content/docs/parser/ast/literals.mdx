Literals live in `FFI\Parser\Node\Literal` and implement `LiteralInterface`, which is an
expression. Every literal keeps its source text in `raw` and gives the parsed value next to it.
All properties are `readonly`.

| Class | Source | Value |
|---|---|---|
| `DecIntLiteral`, `HexIntLiteral`, `OctIntLiteral`, `BinIntLiteral` | `42`, `0x1F`, `017`, `0b101` | `value`, `decimal`, `suffix`, `isImaginary` |
| `DecFloatLiteral`, `HexFloatLiteral` | `1.5e3f`, `0x1.8p3` | `value`, `mantissa`, `exponent`, `suffix`, `suffixWidth`, `isImaginary` |
| `CharLiteral` | `'x'`, `u8'x'` | `value`, `prefix` |
| `StringLiteral` | `"text"`, `L"wide"` | `value`, `prefix` |
| `BoolLiteral` | `true`, `false` | `value` |
| `NullptrLiteral` | `nullptr` | |

The base of a number is the class of the node.

```php
use FFI\Parser\Parser;

$sources = [
    'int a = 0x1Fu;',
    'int a = 017;',
    'double a = 1.5e3f;',
    'char *a = L"hi";',
];

foreach ($sources as $source) {
    $literal = new Parser()->parse($source)[0]->initializer;

    echo new ReflectionClass($literal)->getShortName() . ' ' . $literal->raw . ' ' . var_export($literal->value, true) . "\n";
}

// HexIntLiteral 0x1Fu 31
// OctIntLiteral 017 15
// DecFloatLiteral 1.5e3f 1500.0
// StringLiteral L"hi" 'hi'
```

## Integers

`value` is an `int`, and it saturates at `PHP_INT_MAX` for a constant that does not fit. The exact
value is in `decimal`, a numeric string of any length:

```php
use FFI\Parser\Parser;

$literal = new Parser()->parse('unsigned long long a = 123456789012345678901234567890;')[0]->initializer;

echo $literal->value . "\n";
echo $literal->decimal . "\n";

// 9223372036854775807
// 123456789012345678901234567890
```

The suffix is an `IntTypeSuffix` case, or `null`: `Unsigned` (`u`), `Long`, `UnsignedLong`,
`LongLong`, `UnsignedLongLong`, `BitPrecise` (`wb`), `UnsignedBitPrecise`, and the MSVC sized ones
`Int8`...`Int64` and `UnsignedInt8`...`UnsignedInt64`. Spellings of one type (`ul` and `LU`) are one
case. `IntTypeSuffix::isSized()` tells the MSVC ones. `isImaginary` is the GCC suffix `i` or `j`.

## Floating constants

`value` is a `float`: `INF` for a constant too large for a double, zero for one too small. The
exact value is the pair `mantissa` and `exponent`, both strings: `1.5` and `3` for `1.5e3`, `1.8`
and `3` for `0x1.8p3`. The base of the exponent is 10 for the decimal and 2 for the hexadecimal
constant.

The suffix is a `FloatTypeSuffix` case, or `null` (a `double`): `Float`, `LongDouble`, `FloatN`,
`FloatNx`, the decimal `Decimal32`, `Decimal64`, `Decimal128`, `DecimalN`, `DecimalNx`, and the GCC
`GnuFloat128` and `GnuFloat80`. For the cases with a width, `suffixWidth` holds it: `16` in `1.0f16`.
`FloatTypeSuffix::isDecimal()` and `hasWidth()` classify the case.

## Characters and strings

`value` is the text between the quotes with the escape sequences expanded. It is UTF-8; an octal
or hexadecimal escape of a narrow literal stays a byte, and a value that does not fit becomes
U+FFFD. A multicharacter constant keeps all of its characters. `raw` is the literal exactly as
written, quotes and prefix included.

The `prefix` is an `EncodingPrefix` case, or `null` for no prefix: `Utf8` (`u8`), `Utf16` (`u`),
`Utf32` (`U`), `Wide` (`L`).

Adjacent string literals are not joined into one: they are a
[`ConcatenatedStringExpression`](../expressions/) with the `parts`.

```php
use FFI\Parser\Node\Expression\ConcatenatedStringExpression;
use FFI\Parser\Parser;

$string = new Parser()->parse('char *s = "a\tb" "c";')[0]->initializer;

var_dump($string instanceof ConcatenatedStringExpression);
echo count($string->parts) . "\n";
echo bin2hex($string->parts[0]->value) . "\n";

// bool(true)
// 2
// 610962
```

## Building literals

The classes of the numbers take the parsed parts in the constructor, and the `raw` text, if
omitted, is spelled out of them. That makes it possible to build a node by hand, for example in a
[transformer](../../transformers/#writing-a-rule):

```php
use FFI\Parser\Node\Literal\IntLiteral\HexIntLiteral;

echo new HexIntLiteral(255)->raw . "\n";

// 0xff
```
