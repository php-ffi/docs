`ffi/c-parser` parses C headers, the ones you pass to
[`FFI::cdef()`](https://www.php.net/manual/en/ffi.cdef.php), into a syntax
tree. It is useful for generating wrappers and stubs, or for checking a
header before loading it.

The parser follows C23
([ISO/IEC 9899:2024, N3220](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf))
and, through [presets](presets/), the extensions of GCC, Clang, MSVC and
PHP FFI.

## Installation

```bash
composer require ffi/c-parser
```

Requires PHP 8.1 or later.

<Aside type="note">
The package supports PHP 8.1, the examples of this section use the syntax
of the current PHP version.
</Aside>

## Quick start

`Parser::parse()` takes a header and returns a list of declarations, in the
order they are written.

```php
use FFI\Parser\Parser;

$declarations = new Parser()->parse('void move(int dx, int dy);');

echo $declarations[0]->name->value . "\n";

// move
```

The parser reads **preprocessed** source: it does not expand macros or follow
`#include`. Use [the preprocessor](/preprocessor/with-parser/) first.
