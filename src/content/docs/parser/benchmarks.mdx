The numbers below are copied from the README of the package: they were not measured for this
documentation. Each row is the parsing time of one header, the number of nodes of the tree and the
size of the header.

| Header | Time | AST nodes | Header size |
|---|---|---|---|
| `bzip2.h` | 0.007 s | 3869 | 24.1 KiB |
| `cjson.h` | 0.003 s | 1556 | 6.7 KiB |
| `egl.h` | 0.004 s | 2694 | 16.4 KiB |
| `lua.h` | 0.013 s | 6916 | 39.3 KiB |
| `sqlite3.h` | 0.017 s | 8944 | 41.6 KiB |
| `zlib-no-markers.h` | 0.011 s | 6367 | 33.5 KiB |
| `zlib.h` | 0.012 s | 6367 | 50.4 KiB |
| `zstd.h` | 0.004 s | 2033 | 18.6 KiB |
| `glfw.h` | 0.185 s | 81865 | 344.4 KiB |
| `vulkan.h` | 0.311 s | 117375 | 1.05 MiB |
| `windows.h` | 0.396 s | 140673 | 1.05 MiB |

The environment of the measurements:

- PHP 8.5, with OPcache and JIT 1205
- Windows 11
- AMD Ryzen 9 5900X
- SanDisk Ultra II SSD (240 GB)

These are not benchmarks in the strict sense: the results depend on the environment and the
machine. The headers `bzip2.h`, `cjson.h`, `egl.h`, `lua.h`, `sqlite3.h`, `zlib.h`, `zlib-no-markers.h`,
`zstd.h` and `windows.h` are in `tests/resources/headers` of the repository.
