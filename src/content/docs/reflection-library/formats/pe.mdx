PE (Portable Executable) is the format of `*.dll` and `*.exe` files on Windows. PE images
are always little-endian, and a file with the PE header but without the DLL flag is reported as
`ReflectionLibraryType::Executable`.

## Exports

Exports come from the export directory and are `PeReflectionExportSymbol` objects. Every
entry is addressed by an ordinal and may or may not have a name. In addition to the
[common methods](../../exports/) there is `getOrdinal()`, the position of the symbol in the
export address table (the index shifted by the base of the directory).

All PE exports are `Global` and `Public`. Three details are specific to the format:

- An entry may be a forwarder (`getForwarder()` returns `NTDLL.RtlAcquireSRWLockExclusive`
  and the like) and has no code of its own.
- An entry declared with the `NONAME` attribute has no name: `getNativeName()` and
  `getName()` are `null`, `getOrdinal()` is the only way to refer to it, and `echo $symbol`
  prints `#ordinal`.
- In a 32-bit image the calling convention is recovered from the decoration of the name
  (`_name@8` is `StdCall`, see the [table](../../exports/#binding-visibility-and-calling-convention)).
  The decorated name is not a C identifier, so such a symbol has a native name and no
  public one.

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('kernel32.dll');

$symbol = $library->getSymbol('AcquireSRWLockExclusive');

echo $symbol->getOrdinal() . "\n";
echo $symbol->getForwarder() . "\n";
var_dump($symbol->getAddress());

// 1
// NTDLL.RtlAcquireSRWLockExclusive
// NULL
```

A forwarder has no address of its own: `getAddress()` returns `null`.

## Imports

Imports come from two places: the regular import directory and the delay-load directory.
Each descriptor is a `PeReflectionImport` with all the symbols taken from that DLL, since
PE has a two-level namespace.

A DLL from the delay-load directory is loaded on the first call of one of its functions, not
when the image is loaded. The package reports it as optional, and `isDelayLoaded()` is a
named alias of `isOptional()`:

```php
use FFI\Reflection\ReflectionLibrary;
use FFI\Reflection\ReflectionLibrary\Reader\PE\PeReflectionImport;

$library = new ReflectionLibrary('kernel32.dll');

foreach ($library->getImports() as $import) {
    if ($import instanceof PeReflectionImport && $import->isDelayLoaded()) {
        echo $import->getName() . "\n";
    }
}

// ext-ms-win-oobe-query-l1-1-0.dll
// ext-ms-win-packagevirtualizationcontext-l1-1-0.dll
// RPCRT4.dll
```

An imported symbol (`PeReflectionImportSymbol`) has `getOrdinal()`. The ordinal is set only
for a symbol imported by number, which has no name (it is anonymous and prints as `#ordinal`).
For a symbol imported by name it is `null`, because the image does not record it. Symbols
are never versioned, so `getVersion()` is `null`.
