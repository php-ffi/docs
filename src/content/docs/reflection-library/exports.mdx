Exported symbols are the functions and variables a library offers. They
are the names an `FFI::cdef()` declaration may mention.

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('kernel32.dll');

$symbol = $library->getSymbol('CreateFileW');

echo $symbol->getName() . "\n";
echo '0x' . dechex($symbol->getAddress()) . "\n";

var_dump($library->hasSymbol('CreateFileW'));
var_dump($library->findSymbol('DoesNotExist'));

// CreateFileW
// 0x572c0
// bool(true)
// NULL
```

| Method | Returns |
|---|---|
| `getSymbols()` | `list<ReflectionExportSymbol>`. |
| `getSymbol($name)` | The symbol or `SymbolNotFoundException`. |
| `findSymbol($name)` | The symbol or `null`. |
| `hasSymbol($name)` | `bool`. |

Lookup is case sensitive and goes through the public name of a symbol
(see below). The first symbol wins if names repeat. Addresses depend on
the build of the library.

## Symbol data

| Method | Returns |
|---|---|
| `getName()` | The name for `FFI::cdef()`, or `null`. |
| `getNativeName()` | The name as the file stores it, or `null`. |
| `getAddress()` | `?int`, relative to the base of the library. |
| `getForwarder()` | `?string`, `Library.Symbol` of a forwarder. |
| `getAbi()` | `ReflectionSymbolAbi`, the calling convention. |
| `getBinding()` | `?ReflectionSymbolResolution`: `Global`, `Weak`, `Unique`. |
| `getVisibility()` | `ReflectionSymbolVisibility`. |

Helpers: `isForwarded()`, `isWeak()`, `isAnonymous()` (no native name)
and `isResolvable()` (has a public name).

## Names

`getNativeName()` is what a disassembler shows, decorations included.
`getName()` is the same name when it is a valid C identifier, otherwise
`null`. A symbol without a public name cannot be found by `getSymbol()`:
iterate over `getSymbols()` to reach it.

Mach-O adds an underscore to every C symbol. The native name keeps it,
the public one does not:

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('libsqlitejdbc.dylib');

$symbol = $library->getSymbol('JNI_OnLoad');

echo $symbol->getNativeName() . ' ' . $symbol->getName() . "\n";

// _JNI_OnLoad JNI_OnLoad
```

A 32-bit Windows DLL may decorate names with the calling convention
(`_IsProcessHooked@0`). Such a name is not a C identifier, so
`getName()` is `null`, but `getAbi()` tells the convention:

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary(
    'C:/Windows/SysWOW64/AppVEntSubsystems32.dll',
);

foreach ($library->getSymbols() as $symbol) {
    if ($symbol->getAbi()->name === 'StdCall') {
        var_dump($symbol->getNativeName(), $symbol->getName());
        break;
    }
}

// string(18) "_IsProcessHooked@0"
// NULL
```

## Forwarders

A forwarder has no code of its own and passes calls to another library.
Its address is `null`. `kernel32.dll` has many of them:

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('kernel32.dll');

foreach ($library->getSymbols() as $symbol) {
    if ($symbol->isForwarded()) {
        echo $symbol->getName() . ' => '
            . $symbol->getForwarder() . "\n";
        break;
    }
}

// AcquireSRWLockExclusive => NTDLL.RtlAcquireSRWLockExclusive
```

The result is a plain array, so the pipe operator fits:

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('sqlitejdbc.dll');

$names = $library->getSymbols()
    |> array_map(fn($symbol) => $symbol->getName(), ?)
    |> array_filter(?, fn($name) => str_starts_with($name, 'JNI_'));

echo implode(', ', $names) . "\n";

// JNI_OnLoad, JNI_OnUnload
```

Extra data of a particular format (ELF symbol type, PE ordinal) is in
[Formats](../formats/).
