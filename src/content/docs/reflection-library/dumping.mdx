`ReflectionLibrary` implements `Reflector`: casting it to a string
renders the library the way `ReflectionClass` renders a class. It is
handy for a quick look and for debugging.

```php
use FFI\Reflection\ReflectionLibrary;

echo new ReflectionLibrary('libsqlitejdbc.so');
```

The output, shortened with `...` (the real one lists every symbol):

```text
Library [ <library> <amd64> <little-endian> 64bit libsqlitejdbc.so ] {
  @@ /path/to/libsqlitejdbc.so

  - Imports [3] {
    Import [ libm.so.6 ] {

      - Symbols [23] {
        Symbol [ log10@GLIBC_2.2.5 ]
        ...
      }
    }
    ...
  }

  - Symbols [68] {
    Symbol [ Java_org_sqlite_core_NativeDB_value_1blob ] { 0x0000F7F1 }
    ...
  }
}
```

The header holds the type, the architecture (omitted when unknown), the
byte order, the address size and the file name. `@@` is the full
pathname. Exported symbols show their address, or the target of a
forwarder.

A modifier in angle brackets is printed when a property is not the
default: `<optional>`, `<forwarded>`, `<weak>`, and `<protected>`,
`<private>` or `<internal>` for the visibility. From `kernel32.dll`:

```text
Symbol [ <forwarded> AcquireSRWLockExclusive ] { NTDLL.RtlAcquire... }
Import [ <optional> ext-ms-win-oobe-query-l1-1-0.dll ] {
```

The first line is cut with `...`. The text is made by
`ReflectionPrinter::print()`, which the cast calls.
