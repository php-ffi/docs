All exceptions extend `FFI\Reflection\Exception\ReflectionException`,
which extends the
[`ReflectionException`](https://www.php.net/manual/en/class.reflectionexception.php)
of PHP. Catch `LibraryException` for every problem with a particular
library.

| Exception | Thrown when |
|---|---|
| `LibraryNotFoundException` | The name resolves to no file. |
| `LibraryNotReadableException` | The file cannot be opened. |
| `UnsupportedFormatException` | Not ELF, PE or Mach-O (or a fat Mach-O). |
| `CorruptedBinaryException` | The contents do not add up. |
| `SymbolTableNotFoundException` | The file has no table of symbols. |
| `ImportNotFoundException` | `getImport()` finds no such import. |
| `SymbolNotFoundException` | `getSymbol()` finds no such symbol. |

`SymbolNotFoundException` and `SymbolTableNotFoundException` extend
`SymbolException`, which extends `LibraryException`; so do the others
above. `StreamException` (a low level stream cannot be used) extends
`ReflectionException` directly and is not thrown by the facade.

The first three come from the constructor. The others come from the
call that first reads the data. Lookup misses are not defects of the
file: use `find*()` and `has*()` when a missing name is normal.

```php
use FFI\Reflection\Exception\LibraryException;
use FFI\Reflection\Exception\LibraryNotFoundException;
use FFI\Reflection\ReflectionLibrary;

try {
    $library = new ReflectionLibrary('missing.so');
} catch (LibraryNotFoundException $e) {
    echo $e->getMessage() . "\n";
}

try {
    echo new ReflectionLibrary('truncated.dylib')->getBits();
} catch (LibraryException $e) {
    echo $e::class . "\n" . $e->getMessage() . "\n";
}

// FFI library "missing.so" does not exist
// FFI\Reflection\Exception\CorruptedBinaryException
// Load command #1 has an invalid size of 0 bytes
```

Here `truncated.dylib` is the first 100 bytes of a real dylib.
