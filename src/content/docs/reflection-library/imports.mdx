Imports are the dependencies of a library: each one has a name and the
list of symbols the file takes from it.

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('sqlitejdbc.dll');

foreach ($library->getImports() as $import) {
    echo $import->getName() . ': '
        . count($import->getSymbols()) . " symbols\n";
}

// KERNEL32.dll: 75 symbols
// msvcrt.dll: 52 symbols
```

| Method | Returns |
|---|---|
| `getImports()` | `list<ReflectionImport>`. |
| `getImport($name, $caseInsensitive)` | The import or `ImportNotFoundException`. |
| `findImport($name, $caseInsensitive)` | The import or `null`. |
| `hasImport($name, $caseInsensitive)` | `bool`. |

The name is compared as the file spells it. Windows names are case
insensitive, so pass `caseInsensitive: true` there:

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('sqlitejdbc.dll');

var_dump($library->hasImport('kernel32.dll'));
var_dump($library->hasImport('kernel32.dll', caseInsensitive: true));

echo $library->getImport('kernel32.dll', true)->getName() . "\n";

// bool(false)
// bool(true)
// KERNEL32.dll
```

The name is whatever the format records (`KERNEL32.dll`, `libc.so.6`,
`/usr/lib/libSystem.B.dylib`); it is not resolved on the file system.

## Symbols of an import

`ReflectionImport` has `getSymbols()`, `getSymbol()`, `findSymbol()` and
`hasSymbol()`. Its symbols follow the [naming rules](../exports/#names)
of exported ones and add:

| Method | Returns |
|---|---|
| `isOptional()` | `bool`: the file works without this symbol. |
| `getVersion()` | `?string`, like `GLIBC_2.2.5`. ELF only. |

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('sqlitejdbc.dll');

$kernel = $library->getImport('KERNEL32.dll');

var_dump($kernel->hasSymbol('CloseHandle'));
var_dump($kernel->findSymbol('NoSuchFunction'));

// bool(true)
// NULL
```

A symbol casts to a string as its native name, with `@version` when it
has one. A Windows symbol imported by number has no name and prints as
`#` and the ordinal.

## Optional imports

`ReflectionImport::isOptional()` tells whether the file can start
without the library: a delay-loaded DLL on Windows, a weak dylib on
macOS. ELF imports are never optional.

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('kernel32.dll');

$names = $library->getImports()
    |> array_filter(?, fn($import) => $import->isOptional())
    |> array_map(fn($import) => $import->getName(), ?);

echo implode("\n", $names) . "\n";

// ext-ms-win-oobe-query-l1-1-0.dll
// ext-ms-win-packagevirtualizationcontext-l1-1-0.dll
// RPCRT4.dll
```

Note that on ELF the symbol list of an import is incomplete, see
[Formats](../formats/#elf).
