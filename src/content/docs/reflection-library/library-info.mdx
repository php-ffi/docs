Four methods describe the file as a whole. They work the same way for
every format.

```php
use FFI\Reflection\ReflectionLibrary;

$library = new ReflectionLibrary('libsqlitejdbc.so');

echo $library->getBits() . "\n";
echo $library->getEndianness()->name . "\n";
echo $library->getArchitecture()?->name . "\n";
echo $library->getType()->name . "\n";

// 64
// Little
// Amd64
// Library
```

| Method | Returns |
|---|---|
| `getBits()` | `int`: `32` or `64`, the size of an address. |
| `getEndianness()` | `Endianness::Little` or `Endianness::Big`. |
| `getArchitecture()` | `?Architecture`, `null` for an unknown machine. |
| `getType()` | `ReflectionLibraryType`. |

`Endianness::HOST` is the byte order of the machine PHP runs on.

`Architecture` has the cases `X86`, `Amd64`, `Arm`, `Arm64`, `RiscV`,
`PowerPc`, `PowerPc64`, `Mips`, `Sparc`, `S390x`, `LoongArch` and
`Ia64`. Always handle `null`:

```php
use FFI\Reflection\ReflectionLibrary;
use FFI\Reflection\ReflectionLibrary\Architecture;

$library = new ReflectionLibrary('sqlitejdbc.dll');

echo match ($library->getArchitecture()) {
    Architecture::Amd64, Architecture::Arm64 => '64-bit',
    Architecture::X86, Architecture::Arm => '32-bit',
    null => 'unknown machine',
    default => 'something else',
} . "\n";

// 64-bit
```

`ReflectionLibraryType` has three cases: `Library` (a shared library),
`Executable` (a program, including a position independent ELF
executable) and `Other` (for example a relocatable object file). The
package reads executables like libraries.
