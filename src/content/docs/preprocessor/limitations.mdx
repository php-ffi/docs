---
title: "Limitations"
description: "What the preprocessor does not support: #line, #embed parameters, __has_embed, _Pragma, __VA_OPT__, __COUNTER__."
sidebar:
  label: Limitations
  order: 7
---

- `#line` is not supported: it throws `UnknownDirectiveException`.
  `__FILE__` and `__LINE__` tell the real file and line.
- `#embed` takes only a file name. `limit`, `prefix`, `suffix` and
  `if_empty` are ignored with a warning. `__has_embed` is not
  supported.
- `#pragma once` recognizes a file by its pathname: the same file
  under two virtual names is included twice.
- `_Pragma` and `__VA_OPT__` are not supported, they stay in the
  output as they are.
- `__COUNTER__` is not defined.
- `__DATE__` and `__TIME__` come from the clock at each replacement,
  not once per run.
