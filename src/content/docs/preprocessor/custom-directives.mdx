Every directive has a handler, an object of
`FFI\Preprocessor\Directive\DirectiveHandlerInterface`. The handlers are in
`$pre->directives`, a repository with these methods:

| Method | Does |
|---|---|
| `find(string $name): ?DirectiveHandlerInterface` | Returns the handler of the name or `null`. |
| `add(string $name, DirectiveHandlerInterface $handler)` | Adds a handler for a name that has none. |
| `replace(string $name, DirectiveHandlerInterface $handler)` | Sets the handler, replacing the one that is there. |
| `remove(string $name)` | Removes the handler, the directive becomes unknown. |

The name is an identifier without `#`. `add()` throws
`FFI\Preprocessor\Directive\Exception\InvalidDirectiveNameException` when the name is taken
or is not an identifier, `replace()` only when it is not an identifier.

## A handler

`handle()` gets the directive and the context and returns the chunks that replace the
directive in the output. Return an empty array to leave nothing.

```php
use FFI\Preprocessor\Directive\DirectiveContext;
use FFI\Preprocessor\Directive\DirectiveHandlerInterface;
use FFI\Preprocessor\Preprocessor;
use FFI\Preprocessor\Runtime\Chunk\TaggedChunk\DirectiveChunk;
use FFI\Preprocessor\Runtime\Chunk\TaggedChunk\GeneratedChunk;

$pre = new Preprocessor();

$pre->directives->add('note', new class implements DirectiveHandlerInterface {
    public function handle(DirectiveChunk $directive, DirectiveContext $context): iterable
    {
        yield new GeneratedChunk(
            content: "/* {$directive->body} */\n",
            source: $directive->source,
            offset: $directive->getPhysicalOffset(0),
        );
    }
});

echo $pre->process("#note hi there\nint x;\n");

// /* hi there */
// int x;
```

`DirectiveChunk` has these properties:

| Property | Meaning |
|---|---|
| `name` | The name of the directive, `note`. |
| `body` | The rest of the line after the name and the blanks after it, `hi there`. |
| `content` | The whole line, from `#`. |
| `source`, `offset` | The file and the offset of the line, as in any [chunk](../result/#chunks). |

The `DirectiveContext` gives the handler what it may change:

| Property | Holds |
|---|---|
| `macros` | The macros at the moment, `#define` and `#undef` change them. |
| `files` | The file system `#include` and `#embed` search. |
| `diagnostic` | The listener of `#error` and `#warning`. |
| `executor` | Preprocesses a file: `$context->executor->execute($file)` returns its chunks. |
| `output` | The open conditional sections, used by the handlers of `#if`. |

A handler throws `PreprocessorException` when the directive cannot be executed.

By default a handler is not run inside a skipped group (`#if 0`). A handler that has to
see the directives there too (to count the nesting) implements
`FFI\Preprocessor\Directive\OutputIndependentDirectiveHandlerInterface`, which is the same
interface without new methods. Only the handlers of the conditional directives need it.

## Replacing a standard handler

The same repository holds the standard ones, so a directive is replaced or removed the
same way:

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();
$pre->directives->remove('define');

try {
    echo $pre->process("#define X 1\n");
} catch (Throwable $e) {
    echo $e::class . "\n";
}

// FFI\Preprocessor\Directive\Exception\UnknownDirectiveException
```

## Pragma processors

The handler of `#pragma` asks its processors one by one: the first that supports the body
executes the pragma, the one nobody supports is passed to the output. A processor is an
object of
`FFI\Preprocessor\Directive\Handler\PragmaDirectiveHandler\PragmaProcessorInterface`:

- `supports(string $body): bool` tells whether the processor takes the pragma. The body is
  trimmed.
- `apply(DirectiveChunk $directive, DirectiveContext $context): iterable` returns the
  chunks that replace the pragma.

The default handler has one processor, `OncePragmaProcessor` for `#pragma once`. To add
yours, replace the handler of `pragma` and list the processors including the standard one:

```php
use FFI\Preprocessor\Directive\DirectiveContext;
use FFI\Preprocessor\Directive\Handler\PragmaDirectiveHandler;
use FFI\Preprocessor\Directive\Handler\PragmaDirectiveHandler\OncePragmaProcessor;
use FFI\Preprocessor\Directive\Handler\PragmaDirectiveHandler\PragmaProcessorInterface;
use FFI\Preprocessor\Preprocessor;
use FFI\Preprocessor\Runtime\Chunk\TaggedChunk\DirectiveChunk;

final class PackPragmaProcessor implements PragmaProcessorInterface
{
    public function supports(string $body): bool
    {
        return str_starts_with($body, 'pack');
    }

    public function apply(DirectiveChunk $directive, DirectiveContext $context): iterable
    {
        return []; // `#pragma pack(...)` leaves nothing in the output
    }
}

$pre = new Preprocessor();
$pre->directives->replace('pragma', new PragmaDirectiveHandler([
    new OncePragmaProcessor(),
    new PackPragmaProcessor(),
]));

echo $pre->process("#pragma pack(1)\n#pragma other\nint y;\n");

// #pragma other
// int y;
```
