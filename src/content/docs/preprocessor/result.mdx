`Preprocessor::process()` returns `FFI\Preprocessor\Result`. It is the output of the run
and everything the run learned on the way. The run goes on while the result is read, so
the output is read once and kept: you can read a result as many times as you wish.

## Output

Cast the result to a string to get the whole text:

```php
use FFI\Preprocessor\Preprocessor;

$result = new Preprocessor()->process("#define A 1\nint a = A;\n");

echo $result;

// int a = 1;
```

`__toString()` joins the output in one string. If you need to know where a piece of the
output came from, iterate the result: it is an `IteratorAggregate` of chunks.

## Chunks

The output consists of chunks, objects of `FFI\Preprocessor\Runtime\Chunk\TaggedChunk`.
The class of a chunk tells what it is:

| Class | Content |
|---|---|
| `SourceChunk` | A part of the source between directives, as it was read. |
| `GeneratedChunk` | A text the preprocessor made: a replacement of a macro invocation, the numbers of `#embed`, a `#pragma` passed to the output. |

Every chunk has these properties:

| Property | Meaning |
|---|---|
| `content` | The text of the chunk. Comments are replaced by a space and line splices are removed. |
| `source` | The file the chunk came from, a phplrt `FileInterface`, `$source->pathname` is its name. |
| `offset` | The offset of the first byte of the chunk in that file. |

`getPhysicalOffset(int $offset)` gives the offset in the file of the byte at the given
offset of `content`: it accounts for the splices and comments that were cut out. For a
`GeneratedChunk` every offset is the place of what the text replaces.

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();
$pre->files->add('a.h', "int a;\n");

$result = $pre->process("#include \"a.h\"\n#define B 2\nint b = B;\n");

foreach ($result as $chunk) {
    echo $chunk::class . ' ' . json_encode($chunk->content)
        . ' from ' . $chunk->source->pathname . ' at ' . $chunk->offset . "\n";
}

// FFI\Preprocessor\Runtime\Chunk\TaggedChunk\SourceChunk "int a;\n" from /a.h at 0
// FFI\Preprocessor\Runtime\Chunk\TaggedChunk\GeneratedChunk "int b = 2;\n" from {entrypoint} at 27
```

## Macros

The macros as they are when the run ends, those of the configuration included:

```php
use FFI\Preprocessor\Preprocessor;

$result = new Preprocessor()->process("#define A 1\n#define F(x) (x)\n#undef A\n");

var_dump($result->hasMacro('A'));
var_dump($result->hasMacro('F'));
echo $result->findMacro('F')::class . "\n";

// bool(false)
// bool(true)
// FFI\Preprocessor\Macro\FunctionLikeMacro\CompiledFunctionLikeMacro
```

- `hasMacro(string $name): bool`
- `findMacro(string $name): ?MacroInterface`, `null` when the name is not defined
- `getMacros(): iterable`, the macros by their names, including the predefined ones

## Files and diagnostics

`getFiles()` returns the file of the source and every file it included, each once, in the
order they were read. `getDiagnostics()` returns the `#error` and `#warning` messages the
run reported, see [diagnostics](../diagnostics/).

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();
$pre->files->add('sys/types.h', "typedef int pid_t;\n");
$pre->files->add('sys/a.h', "#include \"types.h\"\n");

$result = $pre->process("#include <sys/a.h>\n#include <sys/types.h>\n");

foreach ($result->getFiles() as $file) {
    echo $file->pathname . "\n";
}

// {entrypoint}
// /sys/a.h
// /sys/types.h
```

Every getter reads the output to the end first. When the run fails, the getter throws the
same exception as casting to a string would.
