A source defines macros with `#define`: object-like and
function-like, `#` and `##`, `__VA_ARGS__`, as the standard says.
Macros you define from PHP are visible to every run of the
preprocessor.

## Predefined macros

| Macro | Replacement |
|---|---|
| `__FILE__`, `__LINE__` | The file and the line of the name. |
| `__DATE__`, `__TIME__` | The date and the time from the clock. |
| `__STDC__`, `__STDC_HOSTED__` | `1` |
| `__STDC_VERSION__` | `202311L` |
| `__STDC_UTF_16__`, `__STDC_UTF_32__` | `1` |
| `__STDC_EMBED_NOT_FOUND__`, `_FOUND__`, `_EMPTY__` | `0`, `1`, `2` |

The clock is a [PSR-20](https://www.php-fig.org/psr/psr-20/) one, the
system clock by default. Pass your own as `clock:` to the constructor.

## Defining macros

`$pre->macros->define()` picks the kind of macro by the replacement:

| Replacement | Macro |
|---|---|
| none | `#define NAME 1` |
| a string | Object-like, the string is the replacement. |
| a closure without parameters | Object-like, called at each use. |
| a closure with parameters | Function-like, gets the arguments. |

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();

$pre->macros->define('DEBUG');
$pre->macros->define('LEVEL', '3');
$pre->macros->define('TIMES', fn() => 7 * 6);
$pre->macros->define(
    'MAX',
    fn(string $a, string $b) => "(($a) > ($b) ? ($a) : ($b))",
);

echo $pre->process("DEBUG LEVEL TIMES MAX(1, 2)\n");

// 1 3 42 ((1) > (2) ? (1) : (2))
```

A closure gets the arguments as text, as they are written, and its
result is cast to a string. The returned text is rescanned for macros.
A variadic parameter takes the rest of the arguments as one string,
commas included.

`$pre->macros->remove('DEBUG')` is `#undef DEBUG`.

A value of another type (`int`, `null`, an object) throws
`InvalidMacroException`, as does a name that is not an identifier.
