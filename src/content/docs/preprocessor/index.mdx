`ffi/preprocessor` is a C preprocessor written in PHP. It implements the preprocessing
phases of C23 ([ISO/IEC 9899:2024, draft N3220](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf)):
it removes comments and line splices, executes the directives and expands the macros of a
C source. The result is a plain C text that `FFI::cdef()` or the [parser](/parser/) can read.

Use it when a header you want to load through FFI is not plain C: it includes other
headers, hides declarations behind `#if`, or builds them with macros.

## Installation

```bash
composer require ffi/preprocessor
```

Requires PHP 8.1 or later. The package does not need `ext-ffi`. It depends on `psr/clock`
and `psr/log`, and on `phplrt` for reading sources.

<Aside type="note">
The package supports PHP 8.1, the examples in this section use the syntax of the current
PHP version, such as `new Foo()->bar()` without parentheses.
</Aside>

## Quick start

`Preprocessor::process()` takes a source and returns a `Result`. The result is stringable:

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();

echo $pre->process(<<<'C'
    #define SQUARE(x) ((x) * (x))

    int area = SQUARE(4);
    C);

// int area = ((4) * (4));
```

A source is a string with the code, an `SplFileInfo`, a stream or any other phplrt
source object, see [usage](./usage/).
