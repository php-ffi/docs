`ffi/preprocessor` is a C preprocessor written in PHP. It follows
[C23](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf):
it removes comments, executes the directives and expands the macros of
a C source. The result is plain C that `FFI::cdef()` or the
[parser](/parser/) can read.

Use it when a header is not plain C: it includes other headers, hides
declarations behind `#if`, or builds them with macros.

## Installation

```bash
composer require ffi/preprocessor
```

Requires PHP 8.1 or later. The package does not need `ext-ffi`.

<Aside type="note">
The package supports PHP 8.1, the examples use the syntax of the
current PHP version.
</Aside>

## Quick start

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();

echo $pre->process(<<<'C'
    #define SQUARE(x) ((x) * (x))

    int area = SQUARE(4);
    C);

// int area = ((4) * (4));
```
