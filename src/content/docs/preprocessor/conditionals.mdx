The directives of conditional inclusion are `#if`, `#ifdef`, `#ifndef`, `#elif`,
`#elifdef`, `#elifndef`, `#else` and `#endif`. The `#elifdef` and `#elifndef` are the
ones C23 added.

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();
$pre->macros->define('API_VERSION', '3');

echo $pre->process(<<<'C'
    #if API_VERSION >= 3 && !defined(LEGACY)
    int modern(void);
    #elif defined(LEGACY)
    int legacy(void);
    #else
    int fallback(void);
    #endif

    #ifndef BUFFER_SIZE
    #define BUFFER_SIZE 4096
    #endif

    #if __has_include(<missing.h>)
    int has_missing;
    #endif

    #if (BUFFER_SIZE / 1024) << 2 == 16 && 'a' == 97 && 0x10 == 16
    int math_ok;
    #endif
    C);

// int modern(void);
// int math_ok;
```

Macros defined from PHP are visible to the conditions the same as `#define`.
This is the way to switch the parts of a header on and off.

## The expression of `#if` and `#elif`

The expression is evaluated as the standard describes (6.10.2):

- `defined X` and `defined(X)` are `1` when the macro exists;
- `__has_include("name.h")` and `__has_include(<name.h>)` are `1` when the
  [file system](../filesystem/) has the file;
- the macros are expanded, then every identifier left is `0`, except `true` which is `1`;
- integer constants (decimal, octal, hexadecimal, binary, with digit separators `'` and
  the `u`, `l`, `ll` suffixes) and character constants;
- the unary, binary and conditional operators of C, shifts and the logical ones
  included. The usual conversions of `intmax_t` and `uintmax_t` apply.

`&&`, `||` and `?:` do not evaluate the operand that is not used, so `0 && 1 / 0` is
valid.

An expression that has no value throws
`FFI\Preprocessor\Directive\Exception\InvalidConditionException`, the message tells why.
The cases are a syntax error, a division by zero, a signed integer overflow, a constant
that does not fit `uintmax_t`, an imaginary constant, and a comma operator in the part
that is evaluated.

```php
use FFI\Preprocessor\Exception\PreprocessorException;
use FFI\Preprocessor\Preprocessor;

$cases = [
    "#if 1 / 0\n#endif\n",
    "#if 0 && 1 / 0\nskipped\n#else\nshort circuit\n#endif\n",
    "#if 1 +\n#endif\n",
    "#if UNKNOWN\nx\n#elif true\ntrue is 1\n#endif\n",
];

foreach ($cases as $case) {
    try {
        echo json_encode((string) new Preprocessor()->process($case)) . "\n";
    } catch (PreprocessorException $e) {
        echo $e::class . ': ' . $e->getMessage() . "\n";
    }
}

// FFI\Preprocessor\Directive\Exception\InvalidConditionException: Invalid controlling expression of #if: Division by zero in the expression
// "short circuit\n"
// FFI\Preprocessor\Directive\Exception\InvalidConditionException: Invalid controlling expression of #if: Syntax error, unexpected end of input
// "true is 1\n"
```

## Structure errors

A missing or extra part of a section throws
`FFI\Preprocessor\Directive\Exception\MisplacedDirectiveException`:

| Source | Message |
|---|---|
| `#if 1` and the end of the file | `#if without #endif` |
| `#endif` alone | `#endif without #if` |
| `#else` alone | `#else without #if` |
| `#elif` alone | `#elif without #if` |

`#ifdef`, `#ifndef`, `#elifdef`, `#elifndef` take one identifier. Extra tokens after it
are a warning (`Extra tokens at the end of #ifdef directive`), an identifier that is
missing throws `InvalidDirectiveBodyException`.

The directives inside a skipped group are only counted to find its `#endif`: a
directive of an unknown name there is not an error.
