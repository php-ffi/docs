## Diagnostics

`#error`, `#warning`, a missing include file and extra tokens after a
directive do not stop the run by themselves. They are reported to a
listener, the `diagnostic` argument of the constructor. By default an
error throws `DiagnosticException` and a warning is skipped.

| Listener | Does |
|---|---|
| `ThrowingDiagnosticListener` | The default. |
| `StreamDiagnosticListener` | Writes a line per message to a stream. |
| `LoggerDiagnosticListener` | Passes messages to a PSR-3 logger. |
| `NullDiagnosticListener` | Does nothing, errors do not stop the run. |
| `CompoundListener` | Passes messages to several listeners. |

They live in `FFI\Preprocessor\Diagnostic\DiagnosticListener`.

```php
use FFI\Preprocessor\Diagnostic\DiagnosticListener\StreamDiagnosticListener;
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor(diagnostic: new StreamDiagnosticListener(STDOUT));

echo $pre->process("#define A 1\n#warning careful\nint x;\n");

// {entrypoint}:2:1: warning: #warning careful
// int x;
```

Whatever the listener is, `Result::getDiagnostics()` lists every
message of the run. A `Diagnostic` has `severity` (`Severity::Warning`
or `Severity::Error`), `message`, `source`, `offset`, `length` and
`findPosition()` for the line and the column.

```php
use FFI\Preprocessor\Diagnostic\DiagnosticListener\NullDiagnosticListener;
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor(diagnostic: new NullDiagnosticListener());

$result = $pre->process("#error boom\nok\n");

echo $result;

foreach ($result->getDiagnostics() as $diagnostic) {
    echo $diagnostic->findPosition()?->line . ': '
        . $diagnostic->message . "\n";
}

// ok
// 1: #error boom
```

## Exceptions

Every exception extends `FFI\Preprocessor\Exception\PreprocessorException`.
The class tells the kind of failure. They are thrown when the result
is read, not by `process()`.

| Exception | When |
|---|---|
| `DiagnosticException` | The default listener got an error. |
| `UnknownDirectiveException` | A directive has no handler. |
| `InvalidDirectiveBodyException` | A malformed `#define`, `#include` and so on. |
| `InvalidConditionException` | An `#if` expression is invalid or has no value. |
| `MisplacedDirectiveException` | `#else` without `#if`, a missing `#endif`. |
| `IncludeDepthException` | Files are nested deeper than the limit. |
| `MacroInvocationException` | A macro call is not closed or has the wrong number of arguments. |
| `InvalidMacroException` | A macro cannot be defined from PHP. |

The ones about a place in the source (`RuntimeException` subclasses)
have `source`, `offset` and `length`, and print with a snippet:

```php
use FFI\Preprocessor\Exception\PreprocessorException;
use FFI\Preprocessor\Preprocessor;

try {
    echo new Preprocessor()->process("int a;\n#if 1 +\n#endif\n");
} catch (PreprocessorException $e) {
    echo $e::class . "\n" . $e->getMessage() . "\n";
}

// FFI\Preprocessor\Directive\Exception\InvalidConditionException
// Invalid controlling expression of #if: Syntax error, unexpected end of input
```

`MacroException` and `FileSystemException` are bases you can catch
for their groups.
