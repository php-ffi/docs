The [parser](/parser/) (`ffi/c-parser`) reads C that is already
preprocessed: it knows nothing about `#include`, `#if` or macros. The
preprocessor does that part first.

```php
use FFI\Parser\Parser;
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();
$pre->macros->define('API_VERSION', '3');
$pre->files->add('api.h', <<<'C'
    #define EXPORT extern
    #if API_VERSION >= 3
    typedef struct { int x; int y; } point_t;
    EXPORT int point_len(point_t p);
    #else
    EXPORT int point_len(int x, int y);
    #endif
    C);

$source = $pre->process('#include "api.h"');

$declarations = new Parser()->parse((string) $source);

foreach ($declarations as $declaration) {
    echo $declaration->name->value . "\n";
}

// point_t
// point_len
```

- `Parser::parse()` does not accept a `Result`: cast it to a string.
- A declaration name is an `Identifier` node without `__toString()`,
  read its `value`.

With `API_VERSION` set to `2` the other branch of the header is
parsed.

A failure of the preprocessor is thrown when the result is read, so
the cast to a string belongs inside the `try` block, see
[diagnostics and errors](../diagnostics/).
