| Directive | Meaning |
|---|---|
| `#define`, `#undef` | Macros, see [macros](../macros/). |
| `#include`, `#embed` | [Includes](../includes/). |
| `#if`, `#ifdef`, `#ifndef`, `#elif`, `#elifdef`, `#elifndef`, `#else`, `#endif` | Conditions. |
| `#error`, `#warning` | [Diagnostics](../diagnostics/). |
| `#pragma` | `once` is executed, others go to the output. |

A lone `#` is skipped. A directive of an unknown name throws
`UnknownDirectiveException`, unless it is in a skipped group.

## Conditions

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();
$pre->macros->define('API_VERSION', '3');

echo $pre->process(<<<'C'
    #if API_VERSION >= 3 && !defined(LEGACY)
    int modern(void);
    #elif defined(LEGACY)
    int legacy(void);
    #else
    int fallback(void);
    #endif
    #if __has_include(<missing.h>)
    int has_missing;
    #endif
    C);

// int modern(void);
```

The expression follows the standard: `defined`, `__has_include`,
integer and character constants, all the C operators. An identifier
left after the macros are expanded is `0`, except `true`, which is
`1`. `&&`, `||` and `?:` skip the operand they do not need, so
`0 && 1 / 0` is valid.

An expression without a value (a syntax error, a division by zero, an
overflow) throws `InvalidConditionException`. A missing `#endif` or a
stray `#else` throws `MisplacedDirectiveException`.

## Pragma once

`#pragma once` includes a file only once. A file is recognized by its
pathname: the same file under two virtual names is included twice.
Any other pragma is passed to the output as it is.

## Your own directive

A handler returns the chunks that replace the directive:

```php
use FFI\Preprocessor\Directive\DirectiveContext;
use FFI\Preprocessor\Directive\DirectiveHandlerInterface;
use FFI\Preprocessor\Preprocessor;
use FFI\Preprocessor\Runtime\Chunk\TaggedChunk\DirectiveChunk;
use FFI\Preprocessor\Runtime\Chunk\TaggedChunk\GeneratedChunk;

$pre = new Preprocessor();

$pre->directives->add('note', new class implements
    DirectiveHandlerInterface
{
    public function handle(
        DirectiveChunk $directive,
        DirectiveContext $context,
    ): iterable {
        yield new GeneratedChunk(
            "/* {$directive->body} */\n",
            $directive->source,
            $directive->getPhysicalOffset(0),
        );
    }
});

echo $pre->process("#note hi there\nint x;\n");

// /* hi there */
// int x;
```

`$pre->directives` also has `replace()` and `remove()`. The context
gives the handler the `macros`, the `files` and the `diagnostic`
listener.

To handle a pragma, add a processor to the `pragma` handler. The first
processor that supports the body runs it, and a pragma nobody supports
goes to the output.

```php
use FFI\Preprocessor\Directive\DirectiveContext;
use FFI\Preprocessor\Directive\Handler\PragmaDirectiveHandler as Pragma;
use FFI\Preprocessor\Preprocessor;
use FFI\Preprocessor\Runtime\Chunk\TaggedChunk\DirectiveChunk;

final class PackProcessor implements
    Pragma\PragmaProcessorInterface
{
    public function supports(string $body): bool
    {
        return str_starts_with($body, 'pack');
    }

    public function apply(
        DirectiveChunk $directive,
        DirectiveContext $context,
    ): iterable {
        return []; // `#pragma pack(...)` leaves nothing
    }
}

$pre = new Preprocessor();
$pre->directives->replace('pragma', new Pragma([
    new Pragma\OncePragmaProcessor(),
    new PackProcessor(),
]));

echo $pre->process("#pragma pack(1)\n#pragma other\nint y;\n");

// #pragma other
// int y;
```
