Every exception of the package extends
`FFI\Preprocessor\Exception\PreprocessorException`, which extends `\Exception`. Catching
it is enough to handle any failure. The kind of the failure is told by the class, the
exception code is always `0`.

A failure of the source is thrown when the [result](../result/) is read, not by
`process()`.

## Exceptions that point to a place

The ones that extend `FFI\Preprocessor\Exception\RuntimeException` carry the place of the
failure: `source` (the file), `offset` and `length` in bytes, `0` when unknown.

```php
use FFI\Preprocessor\Exception\RuntimeException;
use FFI\Preprocessor\Preprocessor;

try {
    echo new Preprocessor()->process("int a;\n#if 1 +\n#endif\n");
} catch (RuntimeException $e) {
    echo $e->source->pathname . ' at ' . $e->offset . "\n";
    echo $e->getMessage() . "\n";
}

// {entrypoint} at 11
// Invalid controlling expression of #if: Syntax error, unexpected end of input
```

Printing the exception (`echo $e`) shows the message with a snippet of the source and the
stack trace:

```text
error[InvalidConditionException]: Invalid controlling expression of #if: Syntax error, unexpected end of input
 --> {entrypoint}:2:5
1 | int a;
2 | #if 1 +
  |     ^^^
3 | #endif
4 |
```

| Class | When |
|---|---|
| `Directive\Exception\UnknownDirectiveException` | A directive has no handler. |
| `Directive\Exception\InvalidDirectiveBodyException` | The body of a directive is not what it takes: a macro name, a header name, a parameter list, `#` not followed by a parameter, `##` at an end of a replacement list, a bad `defined`. |
| `Directive\Exception\InvalidConditionException` | The expression of `#if` or `#elif` is not valid or has no value. |
| `Directive\Exception\MisplacedDirectiveException` | `#else` without `#if`, `#if` without `#endif`, and such. |
| `Directive\Exception\IncludeDepthException` | The files are nested deeper than `maxIncludeDepth`. |
| `Diagnostic\Exception\DiagnosticException` | The default listener received an error, for example `#error`. |
| `Runtime\Exception\UnclosedCommentException` | A file ends in a block comment that is not closed. |
| `Expression\Exception\ExpressionException` | Base of the two below, they are the cause of an `InvalidConditionException`. |
| `Expression\Parser\Exception\SyntaxErrorException` | The text of a condition is not an expression. |
| `Expression\Evaluator\Exception\EvaluationException` | The expression has no value: a division by zero, a signed overflow, a constant that is too large or imaginary, a character constant that does not fit, a comma operator. |

All the names are in the `FFI\Preprocessor` namespace.

## Other exceptions

| Class | When |
|---|---|
| `Macro\Exception\InvalidMacroException` | A macro cannot be defined: a bad name, or a replacement of an unsupported type. |
| `Macro\Exception\MacroInvocationException` | An invocation of a function-like macro is not closed, or has the wrong number of arguments. |
| `FileSystem\Exception\InvalidPathException` | A file is added under the name of the root directory. |
| `FileSystem\Exception\FileNotFoundException` | `link()` of a file that does not exist. |
| `FileSystem\Exception\DirectoryNotFoundException` | `mount()` of a directory that does not exist. |
| `Directive\Exception\InvalidDirectiveNameException` | A handler is registered under a name that is not an identifier or is taken. |
| `Directive\Exception\OutputStackException` | A handler breaks the conditional sections: it closes a section that is not open. |
| `Exception\InvalidStreamException` | The stream of `StreamDiagnosticListener` cannot be used. |
| `Exception\InternalException`, `Exception\PlatformException`, `Runtime\Exception\UnmatchedTextException` | The preprocessor itself failed, not the source. |

`MacroException` and `FileSystemException` are the abstract bases of their groups, so you
can catch the whole group:

```php
use FFI\Preprocessor\Macro\Exception\MacroException;
use FFI\Preprocessor\Preprocessor;

try {
    echo new Preprocessor()->process("#define F(a, b) a b\nF(1)\n");
} catch (MacroException $e) {
    echo $e::class . ': ' . $e->getMessage() . "\n";
}

// FFI\Preprocessor\Macro\Exception\MacroInvocationException: Macro "F" takes 2 arguments, 1 given
```
