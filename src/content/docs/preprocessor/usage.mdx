## Sources

`Preprocessor::process()` accepts:

- a `string`: the source text itself, not a path;
- an `SplFileInfo`: a file;
- a stream resource;
- any `Phplrt\Contracts\Source\ReadableInterface` object.

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor();

echo $pre->process(new SplFileInfo(__DIR__ . '/header.h'));

// int from_disk;
```

A file is known by its real pathname. A string or a stream is known
as `{entrypoint}`: that is what `__FILE__` expands to and what the
diagnostics show.

## The result

`process()` returns a `Result`, which is stringable. The run is lazy:
it goes on while the result is read, and failures of the source are
thrown at that moment, not by `process()`. The result can be read
many times.

```php
use FFI\Preprocessor\Preprocessor;

$result = new Preprocessor()->process(<<<'C'
    #define A 1
    #define F(x) (x)
    int a = A;
    C);

echo $result . "\n";
var_dump($result->hasMacro('F'));
echo $result->findMacro('F')::class . "\n";

// int a = 1;
// bool(true)
// FFI\Preprocessor\Macro\FunctionLikeMacro\CompiledFunctionLikeMacro
```

| Method | Returns |
|---|---|
| `hasMacro($name)` | Whether the macro is defined when the run ends. |
| `findMacro($name)` | The macro object, or `null`. |
| `getMacros()` | All macros by name, predefined ones included. |
| `getFiles()` | The first file and every included one, each once. |
| `getDiagnostics()` | The `#error` and `#warning` messages. |

## Configuration

Every constructor argument is optional and has a name:

| Argument | Default |
|---|---|
| `diagnostic` | Throws on `#error`, skips warnings. |
| `clock` | The system clock, for `__DATE__` and `__TIME__`. |
| `maxIncludeDepth` | `200` files open at once. |
| `macros`, `directives`, `files`, `sources` | The standard ones. |

```php
use FFI\Preprocessor\Preprocessor;

$pre = new Preprocessor(maxIncludeDepth: 20);
```

The object holds the settings every run starts with:
`$pre->macros`, `$pre->files`, `$pre->directives`, `$pre->diagnostic`.
A run works on its own copy: a `#define` in one source is not seen by
the next `process()` call.
